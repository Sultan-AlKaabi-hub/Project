# Intro artwork

Generated with the built-in image-generation tool, using the user's forest, violet-castle and sunset-valley references as visual direction. Final project asset: `public/art/valley.png`.

Prompt: Create an original premium pixel-art game background for Rasid's intro. Landscape 16:9, crisp hand-placed pixel clusters, no text, UI, people or horse. Golden sun and peach clouds; layered misty lavender mountains; a pale stone castle with purple roofs on the distant right hillside; a reflective turquoise stream through a green meadow with flowers; dark foreground foliage. Quiet central area behind UI and a continuous grassy path in the bottom 18% for the animated horse. Warm amber light, emerald/teal vegetation, lavender shadows, atmospheric depth. No photorealism, vector shapes or blur.

The moving rider, birds, grass and light motes are separate code-native canvas layers. The rider crosses the entire screen on a 19-second cycle. Reduced-motion preferences disable automatic animation. The landscape and mist animate independently. No reference image was copied directly into the site.
